Sign in to Monarch with Google?

Set a password in Monarch (Settings → Security) and log in with it here — your Google sign-in keeps working alongside. (Monarch's web app uses cookie sessions, so there's no API token you can copy from the browser; the field below only accepts a token obtained via the API's own login.)

Prefill the calculator

Drag CF Prefill to your bookmarks bar (once). Then open the calculator in its own tab, click the bookmark, and the Shopping values fill in from this tool (Chrome may ask to allow "local network access" — allow it). Reload this page afterwards and the embedded calculator picks them up too (same browser storage).

No bookmarks bar handy? Copy a prefill script and paste it into that tab's DevTools console instead.

Click a category to see its transactions; click the number to copy it. Enter these under Shopping → Advanced in the calculator.
