Carbon Ledger — Privacy

home app methodology

Carbon Ledger is a static web app with almost no server. There is no account, no login, and no database of users. This page says exactly what is stored, what crosses the network, and what is deliberately not collected.

Your financial data stays on your device

When you upload a transactions CSV, the file is read and parsed in your browser. It is not uploaded anywhere. The parsed results — transactions, the industry each merchant was mapped to, and your Travel, Home, Food and Offsets inputs — are written to your browser's localStorage under keys beginning cf_. That is the only copy in existence.

Consequences worth knowing. Nobody can recover your data for you, because nobody else has it. Clearing your browser data, using private browsing, or switching device or browser means starting over. Reset all in the app deletes every cf_ key immediately.

Amounts, dates, account names and the file itself are never sent. The merchant→industry mapping is cached and shared across everyone who uses the app, which is what makes classification fast and nearly free — so a merchant name you upload may be stored in that cache. It is stored with no connection to you, and it contains no amount and no date.

Analytics: what is collected

Usage analytics are first-party — served from this domain, written by this site's own Worker. There is no Google Analytics, no advertising pixel, no third-party script of any kind, and no cookie. That is also why you were not asked to dismiss a cookie banner.

Each event records: the event name (such as page_view, tab_view, upload_done), which page it came from, the referring site's host name, your browser's window width, your country as Cloudflare reports it, a random session id that exists only in the tab's memory and is gone when you close it, and a small number of non-identifying properties — which tab, how many seconds on it, how many transactions were in a file (the count, never the contents).

How a visitor is counted without identifying one. The server derives a short hash from your IP address, your browser's user-agent string, the current UTC date, and a secret. The IP address is never written down. Because the date is part of the hash, today's value cannot be matched to yesterday's — so daily visitor counts work and tracking a person over time does not. This is a deliberate trade: it gives up long-range retention measurement in exchange for not building a profile.

Never collected: your name, email address, or any account identifier (none is ever asked for); merchant names, amounts, dates or account names in analytics events; the contents of any file; your IP address in stored form; anything you typed into an input; and any identifier that persists across days or follows you to another site.

Bot and crawler traffic is discarded at the Worker rather than recorded. If you send a Do Not Track or Global Privacy Control signal, note that the design above collects no personal data to opt out of — but blocking /api/e in your browser or an extension stops analytics entirely, and the app works exactly the same without it.

Abuse protection

The classification endpoint is rate-limited per IP address per day and capped account-wide, to keep one visitor from running up the shared API bill. The counters are keyed by a short-lived record that expires within about a day. If the upload step ever shows a Cloudflare Turnstile challenge, that is a bot check run by Cloudflare; it sets no advertising identifier.

Hosting and retention

The site runs on Cloudflare Workers. Cloudflare processes requests as the infrastructure provider and keeps its own operational request logs under its terms. Analytics events written by this app are kept in a Cloudflare D1 database in the same account; the daily visitor hash means rows older than a day can no longer be linked to a current visitor regardless of how long they are kept.

Anthropic's API is used for merchant classification. Merchant names sent there are subject to Anthropic's privacy policy and commercial terms.

Changes and contact

This app is open source. If a claim on this page is wrong, that is a bug worth filing: open an issue. The code that implements every statement above is in worker/src/index.js and scripts/analytics.py, so you do not have to take this page's word for it.
